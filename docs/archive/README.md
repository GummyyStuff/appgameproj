# Archived Documentation

This directory contains the archived version of the Tarkov Casino project documentation (v0.1).

## About This Archive

All documentation files in this directory represent the previous documentation structure and content that has been superseded by the new documentation system.

The original documentation was migrated from a Supabase-based system to Appwrite, with significant updates including:
- Complete migration from Supabase to Appwrite
- Updates to Bun and Vite tooling
- Real-time features using Appwrite Realtime
- Performance optimizations with Dragonfly caching

## Accessing Original Documentation

To access the original documentation files, navigate to this directory structure:
```
docs/archive/v0.1/
```

This archive was created as part of the v0.1 documentation refresh and migration process.
